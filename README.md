```text

  ▼
TCP Connection
  │

  │
  ▼
Request Parser
  │

  │
```

**Java 21 • Maven • File Storage • B+ Tree**

A small database engine created to explore **storage, indexing and data retrieval**.

### Architecture

```text
              Application
                   │
                   ▼
          ┌─────────────────┐
          │   MiniDB Engine │
          └────────┬────────┘
                   │
          ┌────────┴────────┐
          ▼                 ▼
     ┌─────────┐       ┌───────────┐
     │  Cache  │       │  B+ Tree  │
     └─────────┘       │   Index   │
                       └─────┬─────┘
                             │
                             ▼
                      ┌─────────────┐

                      └─────────────┘
```

### Key Features

* Insert
* Select
* Update
* Delete
* Disk-based storage
* B+ Tree indexing
* In-memory cache
* Basic safeguards for shared data access
